# Portfolio — Ramón Areyuna

Portfolio personal con estética de UI de videojuego: pantalla de título con paisaje de San Juan, árbol de skills interactivo y paneles estilo acuarela.

Sitio estático (HTML, CSS y JavaScript sin dependencias de build).

## Ver en local

Abrí `index.html` en el navegador.

## Estructura

- `index.html` — contenido y paisaje SVG
- `styles.css` — estilos y responsive
- `script.js` — árbol de skills, animaciones
- `assets/` — imágenes
